# guide-dog

This repository is organized into two maintained trees:

- `ZYNQ/guide_dog_main/`: the current Zynq/Vivado camera-to-UDP project.
- `RK/`: RK3568 receiver sources, scripts, and deployment configuration.

Reference projects and historical build material are under `ZYNQ/reference/`.

Private keys, local Vivado state, and transient packet captures are intentionally excluded from Git.
